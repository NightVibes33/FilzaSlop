> **Filza 27 is not presented as a full jailbreak.** It exposes only the files, containers and services that the app can actually access on the current device/build. It does not claim kernel read/write, an SPTM bypass, a root shell or a writable signed system volume.

<details>
<summary><b>Integrated extras — technical details</b></summary>

### Apps Manager / 3105

Apps Manager embeds 3105 and includes application search, icon and disk-size recovery where available, container browsing, file preview, create/rename/import/replace/delete operations, archive support and Patch Workspace handoff.

### ByeTunes

ByeTunes is embedded directly into Filza 27 and includes library browsing, downloads, queue persistence, backups, metadata editing and multi-source metadata routing. The known working pre-v2.4 YouTubeKit metadata path is also restored and its required solver resources are bundled.

### Mond 2.1

Mond is pinned to:

```text
rooootdev/mond@500d76082f0ca021ddd591c05d129ebbc26c20df
```

The preserved upstream tree lives under `ThirdParty/mond-current/Upstream`. The embedded build supplies the standalone Mond app environment that would otherwise be lost inside Filza: its accent color, dedicated preferences domain, bundle identity and resources.

### WebDAV / SSH

Both are in-process services and therefore use the exact filesystem permissions available to Filza itself. iOS can suspend app-hosted networking when the app backgrounds.

</details>

## Compatibility

This fork targets the modern iOS behavior used by its bundled container-access methods, including iOS 18, iOS 26 and early iOS 27 builds.

For iOS 27, useful `bad_query` behavior is associated with beta 1–4. Do not assume identical access on beta 5 or newer. Actual access can vary by device and build.

## Install

1. Download [`Filza-27.ipa`](https://github.com/NightVibes33/Filza-27/releases/latest/download/Filza-27.ipa).
2. Sideload it with your preferred signing method.
3. Keep the base app identity when your signer allows it:

```text
com.apple.mobile.MobileHouseArrest
```

Changing that bundle identifier can break MobileHouseArrest-dependent behavior.

<details>
<summary><b>Build provenance</b></summary>

The installable IPA verifier is:

```text
.github/workflows/verify-upstream-byetunes-ssh.yml
```

It verifies pinned dependencies, validates the Mond source graph, stages required resources, builds the arm64 runtime, packages the anchored Filza base IPA and uploads the exact artifact.

The publisher is:

```text
.github/workflows/publish-green-ipa-release.yml
```

It waits for an exact-SHA green verifier, downloads that artifact, calculates SHA-256 and publishes:

```text
Filza-27.ipa
Filza-27-SHA256.txt
```

</details>

<details>
<summary><b>Limitations</b></summary>

- A green Actions build proves compilation, linking, packaging and artifact verification; it cannot prove every private API behaves identically on every device/build.
- `/System/Library` can be readable while remaining on iOS's signed read-only system volume.
- Access to one App Group or data container does not imply access to the whole filesystem.
- Kernel read/write is not established by this project.
- No full jailbreak, root shell, SPTM bypass or system-volume remount is claimed.

</details>
